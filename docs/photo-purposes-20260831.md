# 照片用途补充记录

## 范围与分类

在“核心定向 → 图片用途”中增加“照片摄影”三级标签，新增 24 项，已有写真与证件照保留 ID 并归入该组。

- 日常与人物：写实照片、日常生活随拍、旅行纪念照、职业形象照、家庭合影、婚礼纪念照、毕业合影、儿童成长记录、孕期纪念照、宠物写真。
- 活动与现场：运动赛事抓拍、活动现场记录、舞台演出照片、手工制作过程照、工业生产纪实。
- 环境与记录：自然风光照片、城市人文街拍、建筑实景记录、房源空间实拍、野生动物生态照片、植物图鉴照片、车辆展示实拍、藏品档案摄影、物品状态记录照。

用途说明交代最终照片需要呈现的信息，不将示例图片中的具体人物、地点和物品写死在参数里。已有美食摄影、珠宝微距、时装型录和产品图继续归入商业电商，不另建同义条目。建筑实景记录与建筑效果图分别表达实景记录和设计可视化；物品状态记录与前后对比展示分别表达单一状态和处理前后的变化。

## 图像来源与裁剪

本批使用 PHOTO_PLTB 流程，四张新生成的 2 列 × 3 行联系表，共 24 张不同用途示例。所有源图、观察到的实际单元格边界和卡片映射记录在 `photo-purposes-20260831.json`。

每格从实际可见边缘再内缩 12 像素。每张成品固定 960×540，以完整缩放方式置入；比例不符处使用该图片自身的模糊背景填充。不使用理论均分结果，不使用相邻图片补边，不更改网页卡片尺寸。

复现命令（路径替换为本机保留的原图目录和临时目录）：

```powershell
backend/.venv/Scripts/python.exe scripts/prepare-photo-purpose-assets.py --source-dir D:/Temp/photo-purposes-20260831 --work-dir D:/Temp/photo-purposes-20260831
backend/.venv/Scripts/python.exe scripts/test_photo_purpose_assets.py
```

原图及审计拼图保存在 D 盘临时目录，不随正式前端资源发布。正式资产位于 `public/assets/parameters/purpose-*.jpg`。

## 数据更新

前端数据位于 `frontend/src/data/photoPurposeParameters.ts`，导出至 `backend/catalog_seed.json`。`0011_photo_purposes` 使用固定增量快照更新已有数据库：仅新增缺失条目，保留管理员修改、上传图片、禁用状态及自定义分组；默认写真和证件照调整到照片摄影组，按组内顺序排列。空库仍通过原有初始化流程导入完整种子数据。

后续部署必须同时包含前端图片、分类数据和后端迁移，已有数据库执行 `python manage.py migrate` 即可获得新增数据，不必用全量导入覆盖管理员编辑。回滚迁移不删除新增内容，避免丢失后续编辑。
